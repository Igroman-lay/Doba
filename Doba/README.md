# Doba

**Doba** — Python-библиотека для получения актуального московского времени в фоновом режиме.

Библиотека самостоятельно обновляет время, не блокируя основной поток программы.

## Возможности

- Асинхронное получение московского времени.
- Автоматическое обновление времени в фоновом режиме.
- Получение последнего сохранённого значения времени.
- Управление запуском и остановкой библиотеки.
- Работа независимо от основного кода приложения.

## Установка

```bash
pip install doba
```

## Использование

```python
import Doba
import time

# Запуск библиотеки
Doba.InitLib()

# Получение времени
for i in range(10):
    print(Doba.ExternalFunc.GetNowTime())
    time.sleep(1)

# Остановка библиотеки
Doba.ExternalFunc.ExitLib()
```

## API

### `Doba.InitLib()`

Запускает библиотеку в отдельном фоновом потоке.

Ожидает первого успешного получения времени, после чего возвращает управление основной программе.

### `Doba.ExternalFunc.GetNowTime()`

Возвращает последнее полученное московское время.

Если время ещё не получено, возвращает `None`.

### `Doba.ExternalFunc.ExitLib()`

Останавливает внутренний цикл обновления времени.
